# Live evaluation · 2 November 2026

Two small Python CLI projects completed with the configured cloud models,
passed independent input/output checks, and resumed without further model
calls or commits. This is a small execution record, not a general success-rate
benchmark. The [machine-readable results](2026-11-02.json) include source hashes
for the copied pipeline used by each case.

## Environment

- Python 3.11.15, Pi 0.87.1, Linux aarch64.
- Planner and consultant: `glm-5.2:cloud`, provider `ollama`.
- Worker: `gemma4:31b-cloud`, provider `ollama`.
- One isolated factory per case; 600-second case deadline, 180-second Pi deadline.
- Automatic mode, no human interventions during either execution.

## Earlier attempts retained

Development runs exposed real limitations. They are included here to avoid
presenting only selected successes; changes between attempts mean these rows
must not be combined into a statistical success rate.

| Candidate | Sum | Slug | What the run exposed |
| --- | --- | --- | --- |
| Initial design gate | Rejected, 22.735 s / 3 calls | Rejected, 19.674 s / 4 calls | Overexpanded plans and design findings |
| Smaller plans | Unverified, 46.926 s / 9 calls | Rejected, 23.189 s / 3 calls | Manifest-free tests were skipped; non-blocking findings violated the JSON contract |
| Test discovery fixed | Unverified, 38.547 s / 10 calls | Passed, 49.058 s / 14 calls | Bare CLI argument validation was mistaken for a runtime crash |
| Runtime and isolation fixed | Passed, 38.593 s / 11 calls | Rejected, 14.019 s / 3 calls | Slug design omitted the behavior for extra arguments |

The sum checker in the “Smaller plans” attempt also had a relative-path bug;
that attempt is diagnostic evidence only. A regression test now covers relative
project paths. The final slug input explicitly specifies missing and extra
argument behavior and independently checks both.

## Reproduce

With model access configured and pytest available:

```bash
PYTHONPATH=factory python -B -m pipeline.evaluate \
  --output .runtime/evaluation-new --case sum --case slug --timeout 600
```

Use a new directory. Outputs may differ across model runs. Raw transcripts,
generated projects and provider diagnostics remain local; this record contains
only selected execution evidence. GUI behavior, larger applications, concurrent
writes, broad model comparisons and billing measurements were not evaluated.
